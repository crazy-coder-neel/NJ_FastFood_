# 🍔 NXT CAPITAL DELIGHT – Built with VB.NET

A complete Fast Food Ordering Website developed entirely using **VB.NET (ASP.NET Web Forms)** with database connectivity using **MySQL**. The application includes dedicated pages for various food categories, an ordering system with invoice generation, and an interactive dashboard to showcase popular items. It's an end-to-end solution suitable for restaurants and food delivery services.

---

## 🌟 Key Features

### 🍕 Multiple Food Pages
- Separate pages for each food category:
  - **Pizza.aspx**
  - **Burger.aspx**
  - **Fries.aspx**
  - **Drinks.aspx**
- Each page displays a menu with prices, images, and ordering options.

### 🛒 Order System
- Users can add items from any category page to their order.
- A summary page displays the selected items and total price.
- Easy navigation between food categories.

### 📄 Invoice Generation
- After placing an order, the app generates a clean and professional invoice.
- Shows customer name, order details, quantity, prices, and total amount.
- Option to print the invoice for records.

### 📊 Dashboard
- Displays trending or most ordered items.
- Quick summary of overall user interactions and food popularity.

### ℹ️ About Us & FAQs
- **About.aspx** provides background info about the restaurant/service.
- **FAQ.aspx** answers common user queries related to orders, delivery, and payment.

---

## 🧰 Technologies Used

- **VB.NET (ASP.NET Web Forms)** – Frontend and backend logic
- **MySQL** – Database connectivity

---

## 📦 How to Run the Project

1. Open the project in **Visual Studio**.
2. Attach or connect the SQL database
3. Run the project using **IIS Express** or any local server.
4. Navigate through the website to explore different food pages, place an order, and view the invoice.
